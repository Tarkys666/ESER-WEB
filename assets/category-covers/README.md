# Category showcase covers

Generated with the built-in Imagegen editor from existing supplier advertising images, then exported as 1200 x 1200 JPEGs at quality 92. These are category illustrations; product-detail photographs are separate.

Shared prompt: remove advertising text, telephone numbers, banners, spec badges and inset photographs; center the referenced equipment on a warm off-white (#ecece7) seamless studio background; use consistent square framing, neutral studio light, contact shadows and generous margins; keep complete equipment visible.

Prompt subjects and references:

- `equipment.jpg`: inspection-camera cable reel, pressure-test pump and thermal camera from `products/1a18e48736e-2ece65f.png`. Initial groups: `aa`, `cc` (both used the same original advertisement).
- `threading.jpg`: black/silver pipe threader, carry case, die heads and accessories from `products/1a18e489c7c-2701fee2.jpg`. Initial group: `bb`.
- `inspection.jpg`: inspection-camera hard case, red cable reel and metal probe from `products/1a18e31747b-3b225a5.png`. Initial group: `bbbbbbb`.

The admin category editor can replace each cover with a square uploaded image. The database stores `cover_path`; removing the custom cover restores the chosen product image fallback.
